workflow-visualizer

把业务流程变成能点、能搜、能导出的交互式流程图 —— 一个 HTML 文件，零依赖、纯离线。

打开示例流程图 →

示例是虚构的「饮品店 · 每日开店到闭店」，用来看分组 / 时间窗 / 状态 / 判断 / 风险点的呈现方式。

  • 点任意环节看 时间 / 负责人 / 说明，高亮上下游、其余淡出
  • 搜索可搜环节、负责人、说明；键盘 Tab / Enter 也能走完整个流程
  • 竖版给手机、横版给电脑，自动切换；可导出 SVG / PNG，也能复制 Mermaid 源码贴进飞书 / 语雀 / GitHub
  • 产物是自包含单文件 HTML：不联网、不装依赖、双击就能看，发给别人也不会坏
